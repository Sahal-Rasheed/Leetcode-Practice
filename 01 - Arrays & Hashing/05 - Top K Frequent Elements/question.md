# Top K Frequent Elements

https://neetcode.io/problems/top-k-elements-in-list/question

![Medium](https://img.shields.io/badge/medium-f5a623?style=for-the-badge&logo=leetcode&logoColor=white)

*Given an integer array `nums` and an integer `k`, return the `k` most frequent elements within the array. You may return the output in any order.*

*The test cases are generated such that the answer is always unique.*

Example 1:
```python
Input: nums = [1,2,2,3,3,3], k = 2

Output: [2,3]
```

Example 2:
```python
Input: nums = [7,7], k = 1

Output: [7]
```

Recommended Time & Space Complexity: O(n) & O(n)

Approach: Hashing (Hash Table), Bucket Sort
