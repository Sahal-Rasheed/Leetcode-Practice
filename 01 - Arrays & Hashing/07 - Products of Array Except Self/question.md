# Products of Array Except Self

https://neetcode.io/problems/products-of-array-discluding-self/question

![Medium](https://img.shields.io/badge/medium-f5a623?style=for-the-badge&logo=leetcode&logoColor=white)

*Given an integer array `nums`, return an array `output` where `output[i]` is the product of all the elements of `nums` except `nums[i]`.*

Example 1:
```python
Input: nums = [1,2,4,6]

Output: [48,24,12,8]
```

Example 2:
```python
Input: nums = [-1,0,1,2,3]

Output: [0,-6,0,0,0]
```

Recommended Time & Space Complexity: O(n) & O(n)

Approach: Array, Prefix and Suffix Product
